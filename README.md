# 💻 NikaForge IDE (妮卡工坊)

> **「用人话搓卡，让卡片动起来！」—— 专为酒馆创作者量身定制的可视化 AI 游戏卡集成开发工具**
>
> 妮卡工坊（NikaForge）依附于 SillyTavern 宿主环境。无论你是想把角色卡打造成**仿真的小手机前端界面、功能丰富的交互 APP，还是全屏交互游戏卡**，只需通过 AI 助手“说人话”，工坊就能自动帮你改代码、搓界面、实时预览，并一键物理打包回你的角色卡 PNG。不需要你懂复杂的编程，就能做出重前端全屏卡！


---

## 🌟 为什么选择妮卡工坊？（对创作者的核心亮点）

对于类脑社区的卡片制作者和玩家来说，以往做一张带炫酷前端画面的游戏卡门槛极高。妮卡工坊就是为了打破这个门槛而生的：

### 1. 🤖 只要“会说人话”，AI 就能帮你搓卡
* **AI 代笔，你来指挥**: 右侧内置了强大的 AI 助手，你可以直接对它说：“*帮我加一个好看的血条*”、“*把背景改成赛博朋克风*”、“*做一个抽卡动画*”。
* **AI 能动笔，不只动嘴**: AI 助手拥有“真实动手能力”（Agent 工具），它能直接帮你阅读你选中的卡片源码，定位到具体的代码行进行增加、删除或精准修改，不需要你手动复制粘贴。
* **酒馆“黑魔法”秘籍自适应**: 首次启动时，工坊会自动将详细的小白X需要了解的 `stscript-reference.md` 指南喂给 AI。AI 能轻松学会编写酒馆专属指令（如 `/genraw`, `/inject` 等），写出的卡片指令更准、Bug 更少。

### 2. 📂 卡片“一键封包”，写完直接发群分享
* **直接改图，无缝打包**: 选中工作区的角色卡 JSON文件，工坊能直接读取里面藏着的网页代码。你在工坊里改完，点击保存，代码就会**直接重新打包写进PNG文件中**。
* **保存即生效，告别重启酒馆**: 很多作者最头疼“修改了代码，酒馆因为缓存不生效，必须重启”。妮卡工坊保存时会**自动帮你把酒馆的临时缓存清理干净**，你只需要在酒馆里随便发个消息或者刷新下网页，就能立刻看到最新的改动。打包好的 PNG 也可以直接发给群友，他们一导入就能直接玩！

### 3. 👁️ 左右分栏，实时预览游戏画面
* **所见即所得**: 中间是完全真实的运行画面预览，支持随时手动刷新，也支持放大缩小和全屏演示。
* **STscript 物理联动调试**: 卡片里的互动按钮（例如触发酒馆命令）可以在预览里直接点击运行，实时呼叫酒馆的生成命令，调试流程极其丝滑。

### 4. 🔄 写崩了也不怕？双重备份保驾护航
* **当前聊天快照 (瞬时还原)**: 工坊会在你当前的聊天过程中实时记录代码微调快照，方便开发时随时回撤。（注意：快照只在当前的聊天会话中生效，一旦新建聊天或切换卡片后就不能回退了）。
* **Git 启动冷备份 (安全大本营)**: 每次启动工坊时，系统都会自动对卡片库进行 Git 级的历史安全冷备份。即使你在调试重前端时遇到重大代码崩溃，也能安全回退到最近一次后端启动时的初始状态。

## 🛠️ 怎么安装和启动？

### 前置依赖：安装与配置“小白X”插件
为了能够让角色卡的前端界面与酒馆进行数据互动，酒馆必须安装并启用“小白X”插件：

1. **安装小白X插件**：
   * 复制开源仓库地址：
     ```text
     https://github.com/RT15548/LittleWhiteBox
     ```
   * 进入 SillyTavern → 打开“扩展程序”管理器 → 点击“安装扩展程序” → 粘贴地址并确认下载。
2. **启用变量管理**：
   * 刷新酒馆页面后，在 **扩展设置 → 小白X** 中，开启 小白X 扩展。（安装了酒馆助手则先关闭，不支持两个同时打开，或者单开酒馆助手）

### 第一步：在酒馆中下载安装

> [!IMPORTANT]
> **⚠️ 必须通过酒馆自带扩展管理器安装！**
> 为了能够实现扩展代码的**自动热更新**，**请勿直接下载 ZIP 压缩包手动解压**。
> 直接下载并手动解压到目录将丢失 Git 信息，导致本扩展后续无法在后台自动拉取更新。

1. 启动你的 SillyTavern 酒馆。
2. 点击左侧导航栏中 **ST 笑脸左边的“扩展程序” (Extensions) 按钮**（即带有积木/插头拼图图标的扩展管理器）。
3. 在弹出的窗口右上角，点击 **“安装扩展程序” (Install Extension) 按钮**。
4. 在弹出的输入框中粘贴本项目的开源地址：
   ```text
   https://github.com/HiUnikitty/NikaForge
   ```
5. 点击下面的 **“只给我安装” (Install) 按钮**，等待酒馆自动克隆并下载完成。

### 第二步：一键启动后端服务

1. 进入你刚刚通过酒馆下载的扩展目录：
   ```text
   SillyTavern/data/default-user/extensions/NikaForge
   ```
2. 双击运行目录下的 **`start.bat`** 批处理文件。
3. 此时会弹出一个黑色的控制台窗口，它会自动帮你检测运行环境（如 Bun 依赖），**并在你的电脑桌面上自动生成一个“NikaForge IDE”快捷方式**（后续直接在桌面双击该快捷方式运行即可）。
> [!IMPORTANT]
> **开发时请不要关闭这个黑色控制台窗口！** 它是 AI 帮你修改文件、打包卡片的核心通道。

### 第三步：在酒馆中启用

1. 刷新你的酒馆网页。
2. 再次点击左侧 **“扩展程序” (Extensions)** 按钮。
3. 在扩展列表中，找到并点击 **💻 妮卡工坊**。
4. 当看到面板中的后端状态灯变为 **“后端已连接”（绿色亮灯）** 后，点击 **“💻 打开 妮卡工坊”** 按钮即可开启全屏开发界面！

## 🧑‍💻 推荐捏卡工作流

1. **准备底卡**: 先在酒馆里准备好一张角色卡（建议先用“妮卡工作室”或酒馆编辑器配置好基本的设定和世界书）。
2. **选择卡片**: 在妮卡工坊的左侧文件列表中，找到并点击该角色卡（PNG 文件），编辑器里就会自动载入卡片内嵌的代码和 JSON 结构。
3. **呼唤 AI 帮工**: 
   * 在右侧聊天框里对 AI 说：“*我想给这个卡片做一个精美的主题商店页面，包含金币和商品列表*”。
   * 观察 AI 自动帮你写好代码，并在编辑器中亮起。
4. **测试与微调**: 在中间预览区测试一下买卖商品的交互，看看动画是不是顺畅，甚至可以直接手敲代码进行微调。
5. **保存打包**: 点击右上角的“保存并聊天”按钮。回到酒馆主界面，最新的前端游戏卡就已经在酒馆里华丽变身了！
